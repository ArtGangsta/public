Quiz Builder & Verification Guide

Create a trivia quiz, test it independently with another AI, fix ambiguity, and only then prepare it for export.

What this guide does

This page is your step-by-step companion for a two-AI trivia workflow. You do not need to know anything about programming or JSON.

The first AI creates the quiz and keeps the answer key. A second AI sees only the questions and answer choices and tries to solve the quiz independently. You then bring those results back to the first AI so it can investigate disagreements.

Why use two AIs?

AI #1 — Quiz Creator

Creates the quiz and knows the intended answers.

It also reviews the questions, prepares the independent test, and later checks the other AI's answers.

AI #2 — Independent Tester

Sees the quiz without the answer key.

Its job is to answer every question itself and point out anything it thinks is ambiguous.

The goal is not simply to have an answer. The goal is to create questions where another knowledgeable AI should independently arrive at the same answer.

1Create the quiz

Start a conversation with the AI you want to use as your quiz creator. Give it the master prompt below.

After copying it, paste it into a new AI conversation and send it. The AI will first ask you how many questions and how many answer choices you want. 

CREATE A TRIVIA QUIZ + PREPARE IT FOR INDEPENDENT AI VERIFICATION

I want you to create a trivia quiz according to the following workflow.

==================================================
STEP 1 — ASK ME FOR THE QUIZ PARAMETERS
==================================================

Before creating anything, ask me these two questions:

1. "How many questions would you like? (10 is recommended, but you can choose any number.)"

2. "How many answer choices would you like for each question? (Choose 4, 5, or 6.)"

Wait for my answers before proceeding.

==================================================
STEP 2 — CREATE THE QUIZ
==================================================

Create exactly the number of questions I specify.

Use exactly the number of answer choices I specify for every question.

QUIZ DESIGN RULES:

- Each question should follow the same basic question pattern.
- Prefer using the same set of answer choices for every question when the quiz format allows it.
- Each question must have exactly one objectively correct answer.
- The correct answer should vary from question to question and be reasonably balanced among the available choices.
- Avoid an obvious pattern in the placement of correct answers.
- Answer choices should be plausible and clearly distinct.
- Choose examples where the correct answer is well-established.
- Avoid questions where two or more answers could reasonably be defended.
- Prefer famous, recognizable examples rather than obscure ones.
- If a subject can have multiple possible answers, choose an example where one answer is clearly the primary, most characteristic, standard, or best-known answer.
- Don't use an example merely because it technically fits; the answer should make good trivia.
- Keep questions concise and easy to read in a chat room.
- Don't give away the answer through the wording of the question.

IMPORTANT:
The goal is not merely to create questions that YOU believe have answers. The goal is to create questions where another knowledgeable AI should independently arrive at the same answers.

==================================================
STEP 3 — VERIFY THE QUIZ YOURSELF
==================================================

Before presenting the quiz, internally check every question:

1. Is the question factually accurate?
2. Is the designated answer factually correct?
3. Is there only ONE reasonable answer?
4. Could another knowledgeable person reasonably interpret the question differently?
5. Are any answer choices overlapping or insufficiently distinct?
6. Is the wording precise enough to avoid ambiguity?
7. Are the correct answers reasonably distributed among the choices?
8. Are the questions interesting and suitable for a general trivia audience?

If a question is ambiguous, revise it before presenting the quiz.

==================================================
STEP 4 — PRESENT THE QUIZ
==================================================

Present the quiz normally, followed by an answer key for ME.

Use this format:

1. [Question]
   A. [Answer choice]
   B. [Answer choice]
   C. [Answer choice]
   D. [Answer choice]

[Continue for the requested number of questions.]

ANSWER KEY:
1. [letter] — [correct answer]
2. [letter] — [correct answer]
3. [letter] — [correct answer]
etc.

You may include a brief explanation for each answer if useful.

==================================================
STEP 5 — INDEPENDENT AI VERIFICATION
==================================================

After I tell you that I like the quiz, I may say something like:

"Prepare this quiz for verification by another AI."

When I do that, create ONE plaintext code block containing a handover prompt for another AI.

The code block must contain:

- The quiz questions.
- All answer choices.
- NO answer key.
- NO explanations that reveal the answers.
- Instructions telling the other AI that this is an independent verification test.
- Instructions to answer every question independently rather than trying to infer what the quiz creator intended.
- Instructions to give its answers in a simple, standardized format.

Use instructions similar to:

"Please independently take this trivia quiz. Do not assume that the quiz creator's intended answers are correct. Determine the best answer to each question yourself. If you believe a question is ambiguous or has more than one defensible answer, explicitly identify it."

Then specify this exact response format:

ANSWERS:
1. A
2. C
3. B
4. D
etc.

After the answer list, instruct the other AI to provide:

AMBIGUOUS QUESTIONS:
- None

or, if applicable:

AMBIGUOUS QUESTIONS:
- Question 4: [brief explanation of the ambiguity]

The handover prompt should NOT contain the original answer key because that would defeat the purpose of the independent verification.

==================================================
STEP 6 — CHECK THE OTHER AI'S ANSWERS
==================================================

After I return with the other AI's answers and say something such as:

"The other AI gave these answers. Confirm whether they are correct."

Compare the other AI's answers against your verified answer key.

For each question, determine whether the other AI selected the correct answer.

Report:

- How many answers were correct.
- How many were incorrect.
- Which questions, if any, were incorrect.
- Whether the other AI identified any ambiguity.
- Whether YOU now believe any question is actually ambiguous.

IMPORTANT:

Do NOT automatically assume your original answer key is correct.

If the other AI gives a different answer from your answer key, re-examine the question carefully. Determine whether:

1. Your original answer was wrong.
2. The other AI was wrong.
3. The question is genuinely ambiguous.

If a question is genuinely ambiguous, tell me that it should be revised before the quiz is exported.

Only tell me that the quiz has passed verification when you are confident that every question has one clear, defensible answer.

==================================================
STEP 7 — EXPORT
==================================================

Once I confirm that the quiz has passed verification, I may ask you to export it to another format, such as Wireclub trivia JSON.

At that point, use the export format/instructions I provide.

Do NOT export to JSON during the initial quiz creation or verification-preparation stages unless I specifically ask you to.

2Work with AI #1

Once the master prompt is pasted, the AI should begin by asking you two questions. Answer them normally.

For example:
How many questions? 10
How many answer choices? 4

The AI then creates the quiz, checks each question internally, and presents the quiz followed by an answer key for you.

Review the quiz before moving on

  • Do you like the subject and questions?
  • Are the questions interesting enough for your chat room?
  • Are the answer choices plausible?
  • Does anything look questionable or confusing?
  • Do you want any questions replaced or rewritten?
Don't move to verification until you're happy with the quiz. You can ask AI #1 to change questions as many times as needed.

3Prepare the independent test

When you are satisfied with the quiz, tell AI #1:

Prepare this quiz for verification by another AI.

AI #1 should respond with one plaintext code block containing a handover prompt. That prompt should include the questions and choices, but deliberately leave out the answer key.

The handover should contain
  • Every question
  • Every answer choice
  • Instructions to solve independently
  • Instructions to identify ambiguity
  • A standardized answer format
The handover must NOT contain
  • The answer key
  • Explanations that reveal answers
  • Hints about the intended answers
Why hide the answers? If the second AI sees the answer key, it cannot independently test the quiz.

4Give the quiz to AI #2

Open a different AI conversation. Paste the entire handover prompt produced by AI #1 and send it.

The second AI is not being asked to guess what the first AI intended. It is being asked to take the quiz as an independent knowledgeable solver.

What you want back

ANSWERS: 1. A 2. C 3. B 4. D etc. AMBIGUOUS QUESTIONS: - None

The exact letters will depend on the quiz. If the second AI thinks a question has more than one defensible answer, it should identify that question and explain why.

5Bring the results back to AI #1

Copy the second AI's response and return to the original AI conversation. Then tell AI #1:

The other AI gave these answers. Confirm whether they are correct.

Paste the other AI's response after that instruction if necessary. AI #1 should compare those answers with its own answer key and investigate every disagreement.

Important: A disagreement does not automatically mean the second AI is wrong. AI #1 is supposed to reconsider the question itself.

What can happen when the AIs disagree?

There are three meaningful possibilities. The purpose of the verification stage is to determine which one actually happened.

🟢 Your original answer was correct The second AI simply chose the wrong answer.
🟡 The other AI was correct AI #1's original answer key needs to be corrected.
🔴 The question is ambiguous More than one answer can reasonably be defended. The question should be revised.
Do not declare victory too quickly. The quiz should only be considered passed when every question has one clear, defensible answer.

What a successful verification looks like

AI #1 should ultimately be able to tell you that the quiz has passed verification only when it is confident that every question has a single clear answer.

Ideally, you want:

  • The second AI's answers match the verified answer key.
  • No question is genuinely ambiguous.
  • Any disagreement has been investigated rather than ignored.
  • Any flawed question has been revised.
  • The final quiz is ready for export.

Common mistakes to avoid

❌ Exporting too early Don't turn the quiz into JSON during creation or verification unless you specifically ask for an export.
❌ Showing AI #2 the answers That defeats the independent test.
❌ Treating every disagreement as an AI error Re-examine the actual wording and choices.
❌ Keeping a questionable question If it is genuinely ambiguous, revise it before export.
❌ Assuming AI #1 can't be wrong The original answer key is supposed to be reconsidered if challenged.
❌ Giving AI #2 extra context The cleaner the independent test, the more useful its result.

🏁 Quiz passed? Now export it.

Once AI #1 confirms that the quiz has passed verification, you are ready for the next stage: converting the finished quiz into Wireclub's JSON format.

Use your Wireclub Trivia — JSON Import Guide for that step. That separate guide contains the Wireclub JSON conversion prompt and explains how to save the resulting JSON file for import.

The important order is:
Create → Review → Independent Verification → Fix Problems → Pass → Export

30-second cheat sheet

  1. Copy the Master Prompt above.
  2. Paste it into AI #1.
  3. Answer the two setup questions.
  4. Let AI #1 create and review the quiz.
  5. Make any changes you want.
  6. Tell AI #1: “Prepare this quiz for verification by another AI.”
  7. Copy the resulting handover prompt.
  8. Paste it into AI #2 without adding the answer key.
  9. Copy AI #2's answers and ambiguity report.
  10. Bring those results back to AI #1.
  11. Let AI #1 investigate disagreements.
  12. Fix any genuinely ambiguous questions.
  13. Once the quiz passes, use the JSON conversion guide.
