Wireclub Trivia Quiz Guide

Create a trivia quiz with ChatGPT or another AI, then turn it into a Wireclub-ready JSON file.

How to use this

You do not need to know anything about JSON or programming. The basic process is:

  1. First, create your trivia quiz. Talk to ChatGPT or another AI and ask it to create a trivia quiz. You can ask for a particular subject, difficulty, number of questions, question types, and so on.
  2. Review the quiz. Continue talking to the AI until you are happy with the questions, answers, and explanations. Make any changes you want before moving on.
  3. Copy the conversion prompt below. This prompt tells the AI exactly how Wireclub's trivia JSON format works.
  4. Paste the prompt into the same AI conversation where your finished quiz was created. Then send it.
  5. The AI should return the quiz as JSON. The JSON must be in a plaintext code block and follow the Wireclub trivia format.
  6. Save the JSON as a file and import that file into Wireclub as a question set.
Important: Do not use this conversion prompt until you are finished editing your quiz. It is intended to take the quiz you already created and convert it into Wireclub's required JSON format.

Wireclub trivia question sets use a JSON file that a user can create offline and import into Wireclub.

The top-level JSON object has two properties:

1. "name" — The name of the quiz.
   - When the user imports the JSON file, they can replace the quiz name during the import process.
   - Therefore, the value of "name" in the JSON file can be ignored.

2. "questions" — An array containing the quiz questions.
   - The array usually contains 10 questions, but it can contain any number of questions.
   - Each question is an object with these properties:
     - "text" — The question text. This property is always required.
     - "explanation" — An optional message that is shown when the answer is revealed. If no explanation is needed, leave this property blank.
     - "type" — The question type. This must be either "multipleChoice" or "writeIn".

For a "multipleChoice" question:

The question object must also contain:

- "options" — A string array containing all answer choices.
- "correctIndex" — The zero-based index of the correct answer in the "options" array.

For example, if "options" contains three choices:

"options": [
  "Option 1",
  "Option 2",
  "Option 3"
]

then:

"correctIndex": 1

means that "Option 2" is the correct answer.

For a "writeIn" question:

The question object must also contain:

- "answer" — The correct answer that players are expected to type in chat.

Example:

{
  "name": "<quiz name>",
  "questions": [
    {
      "type": "multipleChoice",
      "text": "Question text",
      "options": [
        "Option 1",
        "Option 2",
        "Option 3"
      ],
      "correctIndex": 1,
      "explanation": "Explanation shown when the answer is revealed. Optional; leave blank to skip."
    },
    {
      "type": "writeIn",
      "text": "Write-in question text",
      "answer": "Correct answer that players should type in chat.",
      "explanation": "Explanation shown when the answer is revealed. Optional; leave blank to skip."
    }
  ]
}

Convert the provided set of questions into JSON using exactly this format.

Place the resulting JSON in a plaintext code block.

One more tip

If the AI gives you JSON that looks correct, save only the JSON itself as your quiz file. Do not include the surrounding explanation or Markdown code-block markers in the file you import into Wireclub.
